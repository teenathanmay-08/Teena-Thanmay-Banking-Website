# Teena Thanmay Bank — FSD-2 Website

A complete offline, multi-page banking website project.

## Open in one click
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. Use the navigation bar to visit all pages.

No internet connection, server, npm, or database is required.

## Pages
- Home
- About / Managing Director
- Accounts
- Loans
- Services
- Contact

## Theme
Only the website UI theme uses:
- Teal / Deep Blue-Green
- White / Off-White
- Gold

## Important
This is a fictional academic project. Forms show demo success messages and do not process real banking data or transactions.
